Hello and welcome to OccModWhale!

This repo contains scripts and instructions for using occupancy modeling as a framework for distinguishing the effects of sampling limitation from true song change and for identifying key features affecting signal presence and detection over time, as published here: https://onlinelibrary.wiley.com/doi/10.1111/mms.70237 

Instructions for use are in the HOW_TO_USE_OCCMODWHALE pdf. We hope this framework proves useful for you and your project!
